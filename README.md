# Progetto-Rosalia-finale
Il mio corpus di partenza sono testi di Rosalia, dell' album Motomami e Lux. Verrano analizzati a partire da un confronto tra dati numerici e qualitativi. Creerò dei testi tramite Gemini sulla base di dati numerici metriche e strutture degli album, testando la capacità di riconoscimento di un'altro LLM per provare la capacita di crezione di Gemini.
